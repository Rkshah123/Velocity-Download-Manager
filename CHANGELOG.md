# Changelog

## 0.1.0

- Native WPF download manager shell.
- Real HTTP/HTTPS downloads with progress and speed reporting.
- Pause, resume, retry, queueing, cancellation, and HTTP Range segmentation.
- SQLite persistence and settings.
- Scheduler, tray integration, notifications, and optional category organization.
- Chrome, Edge, Brave, and Firefox browser-extension integration.
- Self-contained win-x64 release publishing.
