Velocity browser settings

Download interception, exclusions and appearance

Connection

Checking the Velocity app…

If the app is reported as not reachable, run register-native-host.ps1 from the browser-extension folder once, then reload the extension.

Automatic detection

A small Velocity button appears next to file links and media the page offers, and when the page fetches a file on its own. Each one is verified against the server response first, and nothing is queued until you click it.

Downloads

Downloads the browser starts itself are cancelled and offered to you, one prompt at a time; when several arrive together the rest wait in a queue until the open prompt is answered. Cancel downloads nothing — the browser's copy is already gone. Files under 256 KB are left alone.

When off, verified downloads go straight to Velocity without showing the offer card.

Follow the app theme, or pin the offer card to one theme.

One host per line, for example intranet.example.com.
